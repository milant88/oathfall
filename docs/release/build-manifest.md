# Build manifest contract

Every distributable build records game version, source revision, Unity Editor version, package-lock hash, content revision, active save-schema version, target, build date, and known issues.

Current revision 5 player outputs are `Builds/Oathfall-Revision5-Development/Oathfall.exe` and ordinary `Builds/Oathfall-Hollowwood/Oathfall.exe`, using Unity `6000.3.27f2`, target `StandaloneWindows64`. The old `Oathfall-Windows` output is historical and must not be presented as the current game. See the [revision 5 report](../quality/revision5-presentation-2026-11-01.md) for exact build IDs, evidence and limitations. Source is uncommitted by design; no Git commit was requested.
