# AI task context template

Copy this into `working_knowledge/current/plan.md` before implementation:

1. **Wave and objective:** state acceptance criteria and whether each behavior is planned, implemented, or verified.
2. **Repository/Editor state:** record Unity version, active scene/build target, uncommitted user work, instructions, and relevant package versions.
3. **System context:** list stable content IDs, contracts, test assemblies, and documents consulted.
4. **Implementation plan:** numbered, concrete targets with validation for every step.
5. **Evidence and review:** record changed files, test/build/console evidence, adversarial review findings, and fixes.
6. **Handoff:** exact continuation point, commands, constraints, risks, and unresolved questions.

Never turn temporary task state into a durable specification without updating the relevant document in `docs/`.
