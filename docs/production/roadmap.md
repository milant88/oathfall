# Production roadmap

## Wave 0 — foundation

Create the clean LTS project, local Git/LFS, durable documentation, assembly boundaries, content IDs, and a menu/sandbox scene. Acceptance: a Windows development build reaches a playable menu.

## Wave 1 — combat proving ground

Implement an isometric camera, Dawnwarden movement, attack, block, dodge, basic enemies, combat feedback, and a five-minute arena. Acceptance: keyboard/mouse and controller combat are readable and repeatable.

## Wave 2 — loot proving ground

Implement deterministic items, equipment, drops, pickup, salvage, and six build-changing relics. Acceptance: three Dawnwarden builds emerge from a small catalog.

## Waves 3–9

Hollowwood vertical slice; full hero roster; three-act expedition; expanded itemization; alpha art/accessibility/performance; release preparation; then controlled maintenance. See the approved project plan in task history for the complete acceptance criteria; promote it into dedicated specs as each wave starts.
